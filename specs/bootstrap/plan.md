# Plano

1. Gerar a aplicação com create-next-app oficial em diretório temporário; copiar para a raiz preservando `.agents/` e specs.
2. Usar npm e Node 24 LTS com App Router, TypeScript strict, Tailwind e ESLint.
3. Criar página estática como Server Component e metadata em português, com fontes do sistema. Não há dados externos, secrets ou estados assíncronos.
4. Configurar Prettier, scripts e README. Não instalar testes unitários para uma página estática sem lógica; validar com checks e smoke test HTTP de produção.
5. Conferir os critérios de aceite e registrar evidências.
